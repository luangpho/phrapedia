# sources/ — 一次資料フォルダ

Phrapedia が **最優先・確定情報** として扱う資料の置き場です。AI はレコードを書くとき、まずここを検索・参照し、足りない部分だけを Web 調査（Antigravity CLI / Gemini CLI、結果は「未確認」扱い）で補います。

## 置き方（決まりは最小限）

- **フォルダ構成は自由** です。例: `notes/`, `books/<書名>/`, `images/<寺院名>/`, `scans/` など。
- **Markdown メモ**（`.md`）: 1 行目に `# タイトル` を書いてください。続けて本文・引用・メモを自由に。
  書誌情報（書名・著者・ページ・取材日など）を書いておくと、AI が出典として正確に引用できます。
- **画像**（`.png` `.jpg` `.jpeg` `.gif` `.webp`）: 関連するメモと **同じフォルダに並べて** 置き、メモ側からファイル名で言及すると対応が分かりやすくなります（例: `notes/somdet-to.md` と `notes/somdet-to-1.jpg`）。
- そのほか `.txt` `.csv` `.json` `.yaml` は全文検索の対象、`.pdf` は一覧表示のみ（本文検索は未対応）。
- `.` で始まるファイル／フォルダ、`node_modules` などは無視されます。

## AI による引用

- 検索は部分一致（大文字小文字無視）。タイ語・日本語・英語のどれでも検索できます。
- AI は `search_sources` → `read_source` で資料を読み、レコードの `## 出典` に
  `- 一次資料: notes/somdet-to.md` のように **このフォルダからの相対パス** で記載し、frontmatter の `sources:` にも追加します。
- 一次資料と Web 調査の内容が食い違う場合は一次資料が優先されます。
- アプリはこのフォルダを **読み取り専用** で扱い、書き換えません。

## 場所を変える

既定は `sources/`（データセットパス直下）です。別の場所（例: 外付けドライブや Dropbox）を使うには、画面右上の **設定** → 「一次資料フォルダ」に絶対パス、またはデータセットパスからの相対パスを入力して保存します。

変更後、検索インデックス（アプリデータ dir の `state/phrapedia.sqlite`）は検索時に自動で更新されます。

## 同梱サンプル

`notes/somdet-to.md` と `notes/wat-rakhang.md` は動作確認用の **サンプル** です。実際の資料に置き換えてください。
