# ワット・ラカン 訪問メモ（サンプル）

> **サンプル資料**: 動作確認用の一次資料の例です。実際の訪問記録・文献メモに置き換えてください。

- 正式名: วัดระฆังโฆสิตาราม（ワット・ラカンコーシターラーム）
- 場所: バンコク、チャオプラヤー川西岸（バーンコークノーイ区）。ター・チャーン付近から渡し船。
- 名前の由来: 境内で見つかった鐘（ระฆัง）をラーマ1世がワット・プラケオへ移し、代わりに鐘を寄進したという伝承。
- ソムデット・トー（สมเด็จโต）の像を祀る堂があり、参拝者が多い。
